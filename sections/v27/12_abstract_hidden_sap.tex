\begin{example}[A finite relative cover visible only after naming its fine quotient]
\label{ex:typed-term-visible-index-two-hidden-sap}
Let the ORIGINAL one-sort
real structure be
\[
            M=\mathbb N_{\rm block}
               \times\mathbb F_2
               \times\mathbb N_{\rm clone}.
\]
Name ALL complete symmetric
diversity old pair atoms
$p,q,r$ as follows:
$p$ means SAME block,
SAME bit and distinct
clone points;
$q$ means SAME block
and OPPOSITE bits;
$r$ means DIFFERENT
blocks. Real equality
is the separate
logical diagonal.
Let $K$ be same block
AND same bit, and J
be same block.
Then
\[
  \Id<K<J<\Top,\qquad
  [J:K]=2,
  \quad [K:\Id]=\infty.
\tag{F2C}\label{eq:typed-term-visible-two-cover}
\]

The old real structure
is homogeneous and
transitive: a finite
partial automorphism
preserves the partition
into blocks and the
within-block binary
bit comparison, and
extends by permutations
of the infinitely many
blocks, independent
within-block bit swaps
and arbitrary clone
permutations.
Its finite age has SAP:
in each J-block meeting
the common base, align
the at most TWO
K-classes from the two
extensions compatibly
with their common
already named K-classes,
but identify NO real
vertices. Other new
J-blocks can be kept
disjoint, and the
infinite clone fibres
supply all fresh real
points. It is
triangle-defined
(the triangle with
three mutually
q-related points
would require three
distinct bits).
It has semantic
homomorphic CCO:
a partial diagram of
$p,q,r$ edges is a
system of J-block
equalities/inequalities,
and of $\mathbb F_2$
parity equations
on J-equality edges.
A contradictory
J-inequality is closed
by a J-equality path;
a contradictory bit
equation is a
nonzero-parity cycle.
Choosing a SHORTEST
such witness gives a
specified SIMPLE cycle
with no homomorphism.
In the absence of
these obstructions,
give all J-equality
connected components
distinct block labels,
solve their consistent
bit equations, and use
fresh clone coordinates
to obtain even an
injective old completion.

Now first name ONLY the
nonreal quotient sort
$Q_J=M/J$ and its
projection $p_J$,
together with all ACTUAL
binary original/quotient
orbitals. Call this
finite many-sorted
homogeneous unary
structure $H_J$.
Its homogeneity is direct:
a finite old real/owner
partial isomorphism
preserves the explicit
same-block membership
relation and the fine
old p/q/r atoms, so
extends using the
displayed permutations.
The only distinct
original-real-source
unary TERM FUNCTIONS
are the original real
identity (kernel Id)
and $p_J$ (kernel J).
For $p_J$ the forced
factorisation through
$Q_J$ is the named
identity; for real
identity one has
$[J:\Id]=\infty$.
The REAL-BASE orbit
condition holds:
outside a finite real
set and its named
J-block values,
each real point has
an infinite clone
or new-block orbit,
and each unmentioned
J-block has infinite
orbit. Hence the
abstract iff
\cref{cor:typed-abstract-relative-kernel-sap-iff}
proves
\[
                 \Age(H_J)\text{ has SAP}.
\]
Thus the original
FINITE relative index
$[J:K]=2$ is harmless
to this narrower named
quotient signature.

Next ALSO name the
fine quotient
$Q_K=M/K$, its
projection $p_K$,
and the natural upward
unary map $Q_K\to Q_J$.
Call the resulting
full actual canonical
binary quotient
expansion $H_{K,J}$.
It is still homogeneous
by the same explicit
block/bit/clone
permutation argument.
But the original term
$\tau=p_K$ has kernel
K, and for the
named coarse quotient
J,
\[
                  J\nleq K,\qquad
                  [J:J\cap K]=2.
\]
For each orphan
$b\in Q_J$, EXACTLY
two $Q_K$ points lie
above b. They form
a finite b-definable
set, hence are
algebraic over b,
while the nontrivial
bit swap moves them
and no named unary
term from $Q_J$
selects either one.
Therefore
\[
                 \Age(H_{K,J})
                       \text{ does NOT have SAP}.
\]
This is the precise
term-visible
finite-index obstruction
of
\cref{cor:typed-abstract-relative-kernel-sap-iff}.

In particular global
FULL NR2 is a
SUFFICIENT input for
the terminal MI-only
argument but is
NOT NECESSARY for the
HEREDITARY hidden SAP
of an arbitrarily
chosen smaller
quotient signature.
The exact requirement
is the term-sensitive
criterion (RK)
together with
real-base
nonalgebraicity.
\end{example}

\begin{lemma}[No algebraicity over arbitrary finite hidden closed bases]
\label{lem:typed-hereditary-hidden-orbits}
In the terminal ACTUAL transition-enriched hidden
interpretation $\widehat{\M}$, let $A$ be ANY
finite induced UNARY-FUNCTIONALLY CLOSED
hidden substructure, including one with ONLY
orphan proper quotient vertices.
For every actual hidden vertex $u\notin A$,
\[
       |\Aut(\M/A)\cdot u|=\infty.
 \tag{HO}\label{eq:typed-hereditary-hidden-orbits}
\]
Here $\Aut(\M/A)$ acts on every actual represented
hidden quotient sort and fixes all of $A$ POINTWISE.
Consequently, over an arbitrary finite hidden
parameter set $T$, the orbit-theoretic hidden
algebraic closure equals its finite unary term
closure:
\[
    \operatorname{acl}_{\widehat{\M}}(T)
      =\operatorname{dcl}_{\widehat{\M}}(T)
      =\cl_{\widehat{\M}}(T).
\]
This conclusion is about the named ACTUAL
terminal hidden sorts only; it does not
automatically extend to additional imaginary sorts.
\end{lemma}
\begin{proof}
Apply \cref{lem:foundational-real-frame-orbits} to the actual terminal
hidden structure with the group induced by $G=\Aut(\M)$ on its named
real and quotient sorts. The original real sorts are $G$-invariant,
and every proper quotient vertex is the image of a real point under
its named projection. Finite unary closures are supplied by
\cref{lem:typed-unary-closure-bound}.

For every finite original real $D$, the required infinite $G_D$-orbits
outside $D^{\coord}$ are exactly
\cref{cor:typed-no-real-base-hidden-algebraicity}. For any finite
closed $A\subseteq B$, \cref{lem:typed-fresh-representatives} supplies
real representatives $X$ of all proper vertices of $A$ such that,
with $D=A_{\mathrm{real}}\cup X$,
\[
                    A\subseteq D^{\coord},\qquad
                    D^{\coord}\cap B=A.
\]
These are the two inputs to the general frame lemma. It gives (HO)
for the original group $\Aut(\M/A)$, including orphan-only bases;
no hidden SAP or partial-source completion is used.

For finite hidden $T$, that lemma also identifies the finite-orbit
closure for $G_T$ with $\cl_{\widehat{\M}}(T)$. The full hidden
stabiliser contains $G_T$, so its orbits outside this closure are
infinite as well. Conversely all named unary term values of $T$
are fixed by every hidden automorphism fixing $T$. This proves the
stated algebraic and definable closure equalities for the actual
named hidden structure, retaining the stronger original-group
orbit assertion (HO).
\end{proof}

\begin{example}[An exact non-MI meet quotient can destroy hidden SAP]
\label{ex:typed-exact-nonmi-hidden-sap-failure}
The MEET-IRREDUCIBLE restriction on the
proper quotient sorts in this theorem is
ESSENTIAL, even if the original symmetric
binary source has SAP, homomorphic CCO,
and NO finite relative-index invariant cuts.

Take one original real sort
$M=\mathbb N_{\rm row}\times
\mathbb N_{\rm col}\times\mathbb N_{\rm clone}$,
and name its FOUR complete diversity atoms
by equality/disequality of the row and
column coordinates of DISTINCT real points.
The two coordinate equivalence relations
are independent, and each common cell
has INFINITELY many distinct clones.
This source is homogeneous and has SAP:
the two finite equivalence systems can
be amalgamated freely over their common
classes, while distinct real vertices
are realised by fresh clones even in
one forced common cell.  Its age is
triangle-defined, and semantic HOMOMORPHIC
CCO follows by detecting a coordinate
inequality edge joined by a path of
coordinate equality edges; a shortest
such path gives a forbidden SIMPLE cycle.
Without such an obstruction, give
each equality component a distinct
coordinate and all vertices fresh clones.

Put $J=E_{\rm row}$,
$K=E_{\rm col}$, and
$L=J\cap K=E_{\rm cell}$.
The FULL invariant-equivalence lattice is
\[
       \Id <L<J,K<\Top ,
\]
with ALL strict relative indices INFINITE.
Both $J,K$ are meet-irreducible, but $L$
is NOT.  All three are nevertheless
FULL RAW exact: if $p,u,v$ denote
respectively same-cell distinct-clone,
same-row different-column and same-column
different-row old atoms, then
\[
          L=p;p,\qquad J=u;u,\qquad K=v;v
\]
with the ACTUAL identity diagonal included
in these represented two-step products.

Now INCORRECTLY enlarge the hidden language
by the additional exact NON-MI quotient
sort $M/L$, with its actual unary projections
$\pi_J:M/L\to M/J$ and
$\pi_K:M/L\to M/K$.
Fix one row quotient vertex $a$ and one
column quotient vertex $b$. Their
unary closure $A=\cl\{a,b\}$ contains
no $M/L$ vertex: the stabiliser of
a single row or column acts transitively
on infinitely many cells above it,
so no equivariant unary term can
select a cell. Yet there is a UNIQUE
cell quotient vertex $c\in M/L$
with $\pi_J(c)=a$ and $\pi_K(c)=b$.
It is algebraic, even definable,
over $A$, but not in its unary closure.
Two copies of the finite unary-closed
extension $A\cup\{c\}$ over $A$ CANNOT
be strongly amalgamated: both alleged
distinct new cell vertices must map to
that same unique $c$.

The same obstruction already destroys
SAP in the POINT-GENERATED hidden class.
Choose ORIGINAL real points
$x=(r,c_0,k_0)$ and $y=(r_0,c,k_1)$
with $r\ne r_0$ and $c\ne c_0$.
Their unary closure contains the
row quotient $r$, the column quotient
$c$, and their respective ORIGINAL
cell quotients $(r,c_0)$ and $(r_0,c)$,
but NOT the CROSS cell quotient $(r,c)$.
A third original real point
$z=(r,c,k_2)$ generates precisely
this missing $M/L$ vertex. Yet that
vertex is uniquely determined by
the $J$-coordinate of $x$ and the
$K$-coordinate of $y$. Hence two
copies of the FULL point-generated
structure $\cl\{x,y,z\}$ over
$\cl\{x,y\}$ cannot be strongly
amalgamated either.

Thus \emph{naming all exact quotient sorts}
would destroy even point-generated
hidden SAP, whereas the actual terminal
MI-only hidden signature names
$M/J,M/K$ but NOT $M/L$.
The example does not contradict the
preceding no-algebraicity lemma,
whose exact signature hypothesis is
strictly narrower. Joint quotient
homogeneity by itself does not imply SAP.
\end{example}

\begin{example}[Graph-coupled SAP--CCO with two incomparable MI quotients]
\label{ex:typed-graph-coupled-two-mi}
A POSITIVE non-free-superposition control for the
preceding MI-only hidden algebraicity result is
the Fraisse limit of finite one-sort structures
with TWO original equivalences $R,C$ and
one undirected irreflexive graph edge relation
$G$, subject only to
\[
 \text{no $G$-triangle contained in one
 $R$-class OR one $C$-class}.
\]
Name the complete ORIGINAL diversity atom
$(\epsilon_R,\epsilon_C,\rho)\in\{0,1\}^3$
of each pair, where the first two bits
record membership in $R,C$ and
$\rho$ records $G$-adjacency.
All eight pair atoms occur.
The age is triangle-defined.
Its STRONG amalgamation is the independent
free amalgam of the two equivalence
systems together with NO new cross-factor
$G$-edges: every all-$G$ triangle
then lies in one original factor.
Thus the countable limit is homogeneous,
transitive and has SAP.

For semantic HOMOMORPHIC CCO, a finite
partial old network can violate one
of the two equivalence systems only
via a coordinate-inequality edge
closed by a specified equality path,
giving a forbidden SIMPLE cycle.
If neither coordinate system is
inconsistent, assign distinct labels
to its equality-connected components
and make ALL unspecified $G$-edges
nonedges. A forbidden $G$-triangle
inside one completed equivalence
class would have all THREE graph
edges already specified as $G$.
Each of those specified atoms must
then also carry that coordinate's
EQUALITY bit, else the coordinate
system was already inconsistent.
Thus the triangle itself would be
a specified impossible 3-cycle.
Consequently the partial network
completes injectively whenever
each specified simple cycle maps,
so the source has semantic CCO.

The FULL original invariant-equivalence
lattice is
\[
                   \Id<L=R\cap C<R,C<\Top .
\]
For either $G$-colour (edge or nonedge),
its old atomic-orbital graph generates
exactly $L$, $R$, $C$ or $\Top$
according to its two equality bits.
For nonedges, a two-step path through
a fresh compatible coordinate is enough.
For graph edges, use a two-step path
unless the existing endpoint $G$-edge
would make a forbidden monochromatic
triangle, in which case a three-step
$G$-path with NONEDGE diagonals
works. Every displayed configuration
is a legal triangle-consistent finite
old structure, so exists by homogeneity.
It follows that there are no further
invariant equivalences; all strict
relative indices are infinite.
All four nonidentity equivalences
are FULL RAW exact using the
NONEDGE singleton orbitals:
their ACTUAL twofold RAW products
are respectively $L,R,C,\Top$.
The two proper meet-irreducibles
are $R,C$, with infinite common
meet class $L$.

For the ACTUAL MI-only hidden language
naming $M/R,M/C$ but NOT $M/L$,
every hidden vertex outside ANY
finite unary-closed hidden base $A$
has infinite orbit under
$\Aut(M/A)$. For an off-base REAL
point choose finite real representatives
of orphan quotient vertices of $A$
avoiding that point, then apply old
SAP to obtain infinitely many
real clones over their complete
real diagram. For a new ROW quotient
class, choose such representatives
avoiding that row; Fraisse extension
gives arbitrarily many old points
with its complete original spoke
types over the representatives but
pairwise DIFFERENT fresh row classes
and mutual $G$-NONEDGES.
Old homogeneity transports the
new row class to each of these
different quotient values while
fixing the real representative
frame, hence fixes $A$.
The column case is symmetric.
Therefore hidden
$\operatorname{acl}(A)=A$,
and \cref{lem:unary-homogeneous-sap-criterion}
gives HEREDITARY hidden SAP
independently of the general
typed high-chromatic orbit proof.

This example genuinely couples
a triangle-free $G$-restriction
to BOTH equivalence directions;
it is NOT a free superposition of
an arbitrary graph and equivalences.
Its two MI quotient axes do,
however, still have CARTESIAN
incidence with infinite common cells.
In fact this phenomenon cannot
fail for ANY finite collection of
pairwise compatible nontrivial
ORIGINAL invariant classes in a
terminal symmetric SAP+CCO source:
the general infinite exact-class
Helly corollary
\cref{cor:rh-sap-infinite-exact-helly}
makes their COMMON real intersection
an INFINITE equivalence class.
Therefore a genuinely non-Cartesian
higher-order MI coordinate incidence,
with all pairs compatible but no
joint real point, is EXCLUDED by
the original CCO+SAP hypotheses,
not merely missing from this example.
An additional named exact but
NON-MI quotient $M/L$ would again
destroy hidden SAP by the unique
meet-coordinate obstruction of
\cref{ex:typed-exact-nonmi-hidden-sap-failure}.
\end{example}

\begin{example}[Hierarchical non-Cartesian incidence of three MI quotients]
\label{ex:typed-hierarchical-three-mi}
The terminal MI-only hidden age can have
NON-CARTESIAN quotient incidence and
nontrivial NAMED upward quotient maps,
while still having SAP.
Take ONE original real sort
\[
 M=\mathbb N_{\rm parent}\times
   \mathbb N_{\rm row}\times
   \mathbb N_{\rm col}\times
   \mathbb N_{\rm clone}.
\]
Within each parent the row/column
coordinates are local. Name the
FIVE complete symmetric diversity
old atoms $p,u,v,w,q$,
respectively: same parent/row/column
(different clones); same parent/row
but different column; same
parent/column but different row;
same parent with different row and
column; and different parents.
Real equality is logical.

Every finite complete triangle-legal
old diagram is exactly a triple of
equivalence relations $R,C\le H$,
where $R,C$ record same parent/row
and same parent/column, while
$H$ records same parent.
Independently amalgamate the
$H$-classes and then the $R,C$
class systems within each resulting
$H$-class, always retaining distinct
formal old vertices by choosing
fresh clones in their common cell.
Thus the age has SAP and is
triangle-defined; independent
parent, relative row/column and
within-cell permutations make
its countable limit homogeneous
and transitive.

Semantic HOMOMORPHIC CCO follows
from the same original coordinate
constraint analysis: an incompatible
H-, R- or C-inequality is closed
by a path of corresponding
EQUALITY edges; a shortest such
path with the violating inequality
edge is a forbidden specified
SIMPLE cycle. Here $R,C\le H$
must be respected: R/C equality
edges also impose H equality.
Without any such obstruction,
assign parent labels to H
components, row/column labels
independently inside each parent,
and DISTINCT clone points to all
formal real vertices. This gives
an injective original completion.

The FULL invariant-equivalence
lattice is exactly
\[
                 \Id<L=R\cap C<R,C<H<\Top,
                 \qquad R\vee C=H.
\]
Its complete classification follows
because the connectivity relations
of the original atoms
$p,u,v,w,q$ generate respectively
$L,R,C,H,\Top$; every invariant
equivalence is a union of atoms
and hence their generated join.
Each original invariant
equivalence is ACTUAL FULL RAW
exact, with old products
\[
         p;p=L,\quad u;u=R,\quad
         v;v=C,\quad w;w=H,\quad
         q;q=\Top .
\]
All proper relative indices
are INFINITE by parent/row/column/
clone infinitude. The three
proper NONIDENTITY meet-irreducible
kernels are exactly $R,C,H$;
$L$ is exact but NON-MI.

The ACTUAL MI-only hidden language
names $M/R,M/C,M/H$ but NOT $M/L$,
with named upward maps from row
and column quotients to their
common parent quotient.
Two orphan MI classes from
$M/R$ and $M/C$ are compatible
iff their upward parent images
agree; within that parent
their common real fibre is
INFINITE. For ANY finite
unary-closed hidden base $A$,
an off-base parent quotient
vertex moves through unused
parent blocks, an off-base
row/column quotient vertex
moves through unused local
classes within a fixed parent
(or with an unfixed parent),
and an off-base ORIGINAL real
point moves among infinitely
many clones of its own cell.
These independent permutations
fix every vertex of $A$.
Thus the actual hidden
$\operatorname{acl}(A)=A$,
and the general
\cref{lem:unary-homogeneous-sap-criterion}
gives hereditary MI-only
hidden SAP without invoking the
original high-chromatic
orbit-infinitude argument.

Naming the additional exact
NON-MI cell quotient $M/L$
would destroy that property:
a row class and a column class
with the same parent determine
one UNIQUE $L$-class outside
their named unary closure.
This is the same multi-parameter
algebraicity obstruction as
\cref{ex:typed-exact-nonmi-hidden-sap-failure}.
The example is NON-CARTESIAN
globally, because row and column
classes from DIFFERENT parents
are incompatible, but every
PAIRWISE compatible finite
MI-class tuple still has an
infinite real fibre, by
\cref{cor:rh-sap-infinite-exact-helly}.
\end{example}

\begin{remark}[Graph-coupled hierarchical MI calibration]
\label{rem:typed-hierarchical-graph-mi}
The parent/row/column source of
\cref{ex:typed-hierarchical-three-mi}
can be GENUINELY coupled to an
additional symmetric irreflexive
graph $G$, without losing its
SAP, semantic homomorphic CCO,
full invariant NR2 or its hidden
MI-only algebraicity-free
property. Name the TEN original
fine diversity atoms given by
one of the FIVE hierarchical
pair types and a $G$-edge/nonedge
bit. Forbid $G$-triangles entirely
within ONE row class or entirely
within ONE column class.

This remains triangle-defined.
For strong amalgamation, first
amalgamate the three old
equivalences and declare EVERY
new cross-factor $G$-edge a
NONEDGE. For semantic CCO,
inconsistency of H,R,C
coordinates gives a shortest
forbidden equality-path-plus-
inequality-edge cycle; if those
constraints are consistent, make
all missing $G$-edges nonedges.
Any remaining forbidden
within-row/column $G$-triangle
was already entirely specified
and is itself an impossible
three-cycle. Thus the old partial
network completes.

The ORIGINAL invariant-equivalence
lattice remains exactly
$\Id<L<R,C<H<\Top$:
the NONEDGE original fine
orbital graphs alone have the
same respective connectivity
equivalences $L,R,C,H,\Top$,
and the G-edge orbital graphs
generate no additional invariant
equivalence. In particular all
these equivalences are FULL RAW
exact via squares of the
nonedge singleton atoms,
and the proper MI kernels
are still $R,C,H$.
The original finite frame
selection uses fresh row/column
values with NONEDGE new
adjacencies; each off-base
MI coordinate has infinitely
many old homogeneous
realisations of its complete
fine one-point type over that
frame, choosing all mutual
new $G$-edges as NONEDGES.
Consequently the actual MI-only
hidden age still has SAP by
\cref{lem:unary-homogeneous-sap-criterion},
whereas naming exact NON-MI
cell quotient $M/L$ still
produces the algebraic
meet-coordinate obstruction.

Unlike an unrestricted free
superposition of a graph with
equivalences, the $G$-triangle
forbiddance is conditional on
TWO proper MI quotient classes;
unlike a global Cartesian
coordinate product, row and
column quotients from distinct
parent classes cannot meet.
The proof controls ACTUAL
binary triangles and all simple
specified old cycles, not just
quotient-orbit names.
\end{remark}
