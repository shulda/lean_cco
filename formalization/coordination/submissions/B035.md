## Exact hypotheses and boundaries

The hidden language has finitely many sorts, unary partial FUNCTION graphs
which are single-valued, and positive unary/binary relations; no nullaries or
multiary functions are smuggled in. Actual embeddings reflect function
domains as well as values and preserve/reflect all relations. Normal forms
preserve the entire partial graph on correctly sorted inputs. Root formulas
are genuine qf syntax; roots are literal tagged finite tuples, with no tuple
quotient or representative selection. The selected root subset stays marked.

Reconstruction uses no Ramsey/EP/cofinality input. Ramsey adds only a supplied
hidden embedding-Ramsey property, actual hereditary hidden membership and
the finite normal forms. Its host may have orphans. Ambient cofinality uses
only the ambient age, root coverage and `RootNormalFormsValid` on actual
root-coordinate inputs; it does NOT strengthen A06 to normal forms on every
ambient sort/point.

Ordinary expansions retain the sort set up to its specified renaming.
`LanguageExpansion` constructs the OLD term/qf formula reading and literal
root carrier in the expanded language. Added functions remain permitted.
`SupportReductCommutes` is the explicitly GIVEN A07 equality over the SAME
root presentations, uniformly for hereditary realized root subsets. Finite
normal forms do not imply it. The OLD full-code matching in an allowed
representation is the fixed canonical unexpanded template, not an unrelated
unmarked isomorphism. The marked support equivalence needed for transport is
derived from the constructed FCODE maps, not another assumed provider.

EP retains the stated reasonable precompact hereditary/reduct-surjective
expansion setting and supplied hidden EP. Precompactness and expanded NF
validity are honestly retained where the implemented core is stronger.
The core yields actual complete-code embeddings; the original fine-atom
conclusion uses precisely the supplied D12 faithfulness in `FineAtoms`.

CCO, SAP, EPPA or global CCO candidate theorem is asserted here.
