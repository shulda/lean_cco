## Required proof contract

1. Prove the elementary table laws without an ambient SAP argument:
   monotonicity, converse reversal, finite positive-profile nonemptiness
   and set Peirce. Strong totality and Peirce give return-square absorption
   `c in ({u}*bar(u))*{c}`. This algebraic law handles a closed prefix; it
   does not insert an identity menu.
2. A positive walk mapped to an allowed complete network may repeat
   nonadjacent images. Prove that if its ACTUAL endpoints are distinct,
   their literal colour belongs to the table profile. If the penultimate
   image equals the first point, use the shorter open return tail to get
   `bar(u)` and then return-square absorption. No SAP, Helly or injective
   realization is an input to this readout.
3. Convert an input cycle HOMOMORPHISM to an algebraic closing-edge test by
   cutting at a SPECIFIED diversity edge: those actual images cannot
   collide. Pure associative Peirce rotation then moves the test to all
   other cuts and gives intersections of profiles of two positive arcs.
   Do not cut first at arbitrary nonadjacent terminals and assume their
   images differ. Cycle homomorphisms may identify them.
4. Maintain **ALGEBRAIC simple-cycle compatibility**. It means that every
   closing edge belongs to the complementary positive profile, equivalently
   that every pair of positive arcs around a specified simple cycle has
   intersecting profiles. It does NOT mean that each intermediate cycle
   already has a full semantic completion. The semantic input predicate
   is bound to a particular partial network, not a global CCO assumption.
5. For ALL distinct endpoint pairs, RECORDED or UNRECORDED, take two simple
   specified paths and induct
   on the number of shared internal vertices. Identical paths share their
   nonempty profile; internally disjoint different paths form a simple
   cycle. Otherwise split at ANY common internal vertex. Both prefix-pair
   and suffix-pair have strictly fewer common internal vertices, even if
   the two paths meet them in opposite orders. Totality and associativity
   concatenate atoms from the smaller profile intersections. The split
   subpairs may already have recorded edges; only afterwards specialize
   the uniform theorem to a missing pair for the fill step.
6. Enumerate only the FINITE family of simple specified endpoint paths.
   ALG makes their profiles pairwise intersecting, so given 2-Helly chooses
   one common colour. If there is no specified path, choose from the
   nonempty endpoint palette directly. This case needs no zero-length
   profile or Helly on an empty family.
7. Fill ONE unrecorded unordered DISTINCT pair with that atom and its
   converse, preserving every old edge, vertex and sort. Every new simple
   cycle uses this new edge and an old simple complementary path, whose
   profile contains the chosen atom. Thus ALG is preserved. Never appeal
   here to the completion theorem that the algorithm is proving.
8. The number of missing unordered distinct pairs decreases EXACTLY by
   one. The terminal network is complete on the SAME vertex set, and ALG
   on its triangles is precisely table legality. FULL triangle-definedness
   puts it in K. This proves the GENERIC constructor
   `ALG(G) -> fixed-vertex completion`, independently of the semantic start
   bridge. Combine that bridge with the constructor for the sufficient
   CCO direction; restriction of a homomorphism gives necessity.
9. For SAP, construct exact abstract factor copies over the WHOLE complete
   common base, disjoint outside it. A mixed simple cycle has at least two
   DISTINCT base visits. Split at EVERY base visit; every positive segment
   lies in one factor and its profile contains the actual base-edge colour.
   Exactly TWO base visits contract to a parallel-edge DIGON, not a simple
   cycle: both oriented arc profiles contain the SAME base atom. For at
   least three visits, use the actual base cycle and substitute the factor
   segments algebraically. Empty/singleton bases create no mixed simple
   cycle. This proves ALG of the free partial amalgam without prior SAP.
10. Apply the generic fixed-vertex constructor DIRECTLY to that free partial
    amalgam. It retains all formal vertices and old factor colours, so the
    embeddings remain induced and meet exactly in the prescribed base.
    A merely noninjective homomorphic completion would not suffice.
