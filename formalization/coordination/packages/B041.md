## Exact proof branches

Reverse exact descent is ONLY for ONE original transitive symmetric sort
and an actual nonempty E-bisaturated full exact relation. Prove local
commutation by symmetry/converse, distribute saturation over nonempty
exact meets and identify each saturated old word with a quotient word.
Top is an empty restriction list; old equality is an empty old word;
quotient equality pulls back to E. Do not generalize to independent
mixed-original-sort factorwise word descent.

The private-path cycle lemma is pure finite graph combinatorics. Internal
vertices are formal and private, degree two; simple cycles traverse whole
paths and either use two paths over one edge or project to a SIMPLE base
cycle. Contract genuine identity letters locally, exclude zero-length
paths and merge coincident equal-colour direct edges. A top block can
contribute zero paths while retaining its marked endpoints.

For quotient triangle fullness, align each actual triangle's centre pair
using an ORIGINAL automorphism. Saturated blocks make the two exact balls
meet for arbitrary fixed real representatives. Old heterogeneous ball
Helly supplies one new point; quotient diversity excludes collision with
same-sort old centres. Handle zero/one centre directly. For quotient
homogeneity, apply individual joint exact lifting to the EXACT SAME
displayed quotient vertices, adding no unconstrained fine representatives.

Prove quotient semantic HOM CCO independently of those quotient extension/
homogeneity/AP conclusions. Expand specified quotient edges by private
old paths from exact block presentations. A top presentation has no
restrictions. Every other restriction reduces to a positive-length path:
an all-identity word cannot contain a diversity block. Classify each raw
cycle, choose ONE quotient witness for that whole cycle, then ONE real
representative per marked variable within it. Saturation supplies every
word endpoint condition; private interiors are witnessed independently.
Original CCO completes the whole raw diagram; project its marked images.
No quotient FullWord criterion, SAP or injectivity is imported.

Towers reapply the theorem to CURRENT exact kernels and use SAFE UPWARD
pullback for total original kernels. Flatten nested classes canonically
by `[[x]] -> [x]`; they are not literally the same sets before this map.
Double saturation equals the direct original block. Finite diversity atoms
can merge but never split; any nonidentity current kernel swallows a
same-sort diversity atom into equality, forcing strict total rank loss.

The finite-axis consequence uses FULL Aut(Q) on ENTIRE finite named
quotient sorts. Apply existing whole-axis projection and, only when the
intrinsic coordinate groups are elementary abelian, linear Goursat/rank
count. The count is the finite coordinate IMAGE, not full Gamma. Never
substitute pointwise owner kernels, unnamed fibres or an arbitrary earlier
group action. The phase counterexamples guard these different scopes.
