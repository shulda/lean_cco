## N01: Closed-sort restriction retains the actual language

**D01–D02; C01–C06.** Let I have no outgoing unary function to an outside
sort. Every defined value at an I-point therefore stays in I. The I-part
is an actual functionally closed induced substructure, retaining the full
language with outside sorts empty. If arbitrary relations include nullary
symbols, their induced truth is retained as well. A structure in the
restricted class can be represented as such an all-I ambient object, by
heredity and its inducing isomorphism.

Every sort-preserving embedding of all-I A into C has all its image in
C|I. Since that restriction is induced, the same map is an embedding into
C|I, with identical relation and function-domain tests. Conversely compose
an embedding into C|I with its induced inclusion. Thus the two embedding
sets agree on literal maps, including any nullary truth conditions.

Choose an ambient Ramsey witness for all-I A,B. A coloring into C|I is
therefore a coloring into C; the ambient monochromatic B-copy also lies
in C|I. This proves Ramsey without SAP or choices of real representatives.
Any closed induced substructure of an all-I object is again all-I and in
the ambient class, proving heredity. For optional JEP/SAP, apply the ambient
construction to the all-I input span and restrict its host to I. The maps
and their images are unchanged; strong intersection remains exactly the
old base. SAP is used only in its stated inheritance clause.

## N03: Parent-lex normalization synchronizes FIBRE tasks

**D04–D07; C13–C24.** Work with actual finite distributive equivalence
lattices and their represented proper MI quotient sorts. A meet-irreducible

as a meet of meet-irreducibles above it: recursively split any non-top
element that is not meet-irreducible, terminating in the finite upper
interval. Therefore the meet of ALL strict coarser represented MIs above
J is Jplus, because L>J is equivalent to L>=Jplus. When Jplus is top,
the empty tuple is the one constant parent key.

Upward coordinate maps consequently give equal full strict-coarser keys
for two J-points exactly when they lie in the same Jplus class. All
coordinates are necessary; a selected proper subtuple may merge parent
classes. Lexicographic comparison will only use fibre orders to break
ties inside an actual common parent class.

Named quotient transitions carry more than a bijection: they transport
cuts and upper intervals and commute with the upward maps. Their inverse
terms take every point back to the chosen representative chart INSIDE
the same finite closed hidden object. Restrict the representative's initial
order to each parent fibre and transport this local order to every
equivalent cut. Two paths differ by a closed transition, identity by
holonomy, so the transported order is unambiguous.

Strict coarsening shortens the finite upper interval; transitions preserve
its order type. Hence passing to task orbits cannot create a cycle of
strict coarsenings. Process all tasks from coarser to finer. The already
ordered coarser coordinates give a total lexicographic order of distinct
keys, and the transported fibre task totally orders each equal-key class.
Fixed sort priority handles different sort symbols.

An embedding of initially ordered closed objects preserves the old
representative orders and commutes with every named quotient/transition

then every lex key and local tie-breaker. With injectivity, preservation
of a total order also gives reflection. Other hidden relations and
functions were unchanged. Thus its SAME vertex map is an induced embedding
of normalized objects. Compositions and identities are unchanged.

On a normalized object, extracting representative orders inside each
parent fibre recovers exactly the tasks used in its construction. The
same recursion therefore rebuilds it, proving idempotence. Its image is
precisely the class defined by synchronized FIBRE tasks and the fixed
parent-lex rule; any such object is fixed.

Reverse all local fibre orders of one selected task orbit, transport that
reversal coherently, and retain the other independent task inputs. Its
strict coarser tasks and keys do not change. Recompute all later derived
lex comparisons by the same rule; the same embedding argument applies.
No extra priority or independent host-specific order is chosen afterwards.

**Scope:** synchronization concerns the orders INSIDE each Jplus fibre.

## N07: Concrete boundaries and the displayed-composition counterexample

**C52–C55.** Bounded controls exercise these mechanisms; the all-size
counterexample proof is the mathematical argument here. Diagnostic variants

**Priorities and global transitions.** On a grid with coordinates
(r,c,a,b), take a distributive equivalence lattice with

\[
 \mathrm{Id}<J<P<L,M<\mathrm{Top},\qquad
 J=\text{equality of }(c,a,b),\quad
 P=\text{equality of }(a,b),
\]

and L equality of a, M equality of b. The proper nonidentity MI sorts
are J,L,M and Jplus=P. Use two named copies with transition
(c,a,b) mapped to (c,b,a), inverse the same swap, transporting L to M
and M to L and commuting with the quotient maps. All closed loops are
identity. Both copies can legitimately choose L-before-M parent priorities,
with 0<1 on coarser values and c=0 before c=1 in each fibre. Then
x=(0,0,1) precedes y=(0,1,0) in one J-sort while the transition images
have the opposite lex comparison. Their within-parent task orders remain
synchronized. This disproves only the stronger GLOBAL-monotonicity claim.

**Closure type and freshness.** Two root pairs can have the same visible
two-point relations while F(u)=F(v) in one closure and F(u)!=F(v) in
the other. Their complete pointed closure types differ, so they cannot
be used as the same amalgamation base. Separately, a reset path may use
a vertex already in the pair closure; reachability alone does not give
a point outside the old host. The provider requires that external witness
and strong intersection.

**Function-adding composition counterexample, including JEP.** Define:

- K0: all finite nested equivalences Q contained in P.
- K1: additionally a strict total order with every P-class and Q-class
  convex.
- K2: additionally the TOTAL unary function F equal to immediate
  successor WITHIN each ordered P-class, fixing that class's maximum.

All classes are isomorphism-closed and the reduct maps are surjective.
K0,K1 are hereditary under induced subsets. A functionally closed induced
subset of a K2 object meets each retained P-class in a FINAL SEGMENT;
the restricted F is exactly its own successor/max-fix function. Thus K2
is hereditary under actual function-domain-preserving substructures.
All three have JEP by disjoint union of P-components, ordering each
whole component consecutively at the ordered levels.

K1/K0 has EP. For an ordered source let r be its number of P-classes,
q the maximum number of Q-classes inside one P-class, and n its maximum
Q-class size. Choose a K0 host with r P-classes, each having q Q-classes
of size n. EVERY convex order contains the source by matching its
successive P-classes, then successive Q-classes, then ordered points
inside each equal-sized block. Empty cases are immediate.

K2/K1 has the EP QUANTIFIER trivially: each K1 object has a UNIQUE
K2 expansion, so the reduct of the chosen source is a witness for it.

Composite EP fails for the three-point source

\[
 a<b<c,\quad P\text{ universal},\quad
 Q\text{-classes }\{a,b\},\{c\},\quad
 F(a)=b,\ F(b)=c,\ F(c)=c.
\]

For ANY proposed base host, in EACH P-component place a Q-class of
size at least two LAST if one exists; otherwise order its singleton
Q-classes arbitrarily. This is a legal convex order and has its unique
F expansion. Any embedding of the source sends c to the maximum of its
P-component, because those are exactly the F-fixed points. Since b<c
and F(b)=c, b maps to that maximum's immediate predecessor. If a large
Q-block was last, these two images are Q-related, contrary to b not Q c.
If all Q-blocks in that component were singleton, a Q b is impossible.
Thus this competitor avoids the source for every host, contradicting
the composite EP quantifier.
