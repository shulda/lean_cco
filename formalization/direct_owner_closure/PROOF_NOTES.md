## N01: Greatest finite F, definability and the empty original base

Every invariant binary relation is a union of finitely many actual old
atom names. The full invariant-equivalence lattice is consequently finite.
Its finite-class members are closed under joins: commuting equivalences
have their relational product as join, and the product of two uniform
finite-class equivalences has class size bounded by the product of the
two class bounds. The join of all of them is the greatest finite-class F.
This is precisely the selected elementary packet C03 provider; no assertion
that F is exact or normalized is included.

F is a finite union of named original relations, hence 0-definable. For
finite A the set F[A] is a finite A-definable union of finite classes. It
is preserved by every automorphism fixing A pointwise, so all its points
have finite orbits and are algebraic over A. Reflexivity gives A subset
F[A]. For A empty, the union F[A] is empty. The ambient source is infinite
and transitive, so the full Aut(M) orbit of any point is infinite. Thus
acl_M(empty)=empty. This argument does not assert anything about finite
sources, where all real points would be algebraic over the empty base.

## N02: Direct unary closure by the canonical hull contrapositive

Fix finite NONEMPTY A and x outside F[A]. Then x is not in A. Every spoke
p_a=col(x,a) is genuine diversity and x Gamma(p_a) a, where Gamma(p_a) is
the least actual invariant equivalence containing p_a. It may be NONEXACT.
If this equivalence had finite classes, greatest-finite maximality would
place it below F and give xFa, a contradiction. It has infinite classes.

Every infinite-class member of the finite full invariant lattice contains
a minimal infinite member. There is exactly one such member E, so the
SAME E lies below EVERY Gamma(p_a). Therefore

`E[x] subset intersection_(a in A) [a]_(Gamma(col(x,a)))`.

The left hand side is infinite. The prepared canonical hull theorem says
that an algebraic real x outside A has FINITE displayed intersection.
Its contrapositive excludes x from acl_M(A). We use only that implication,
not an invented equivalence between an arbitrary finite hull and a type
fibre. Combining with N01 and its empty case proves acl_M(A)=F[A] for
EVERY finite real A. AP and CCO remain in the canonical hull source scope;
countability, normalization, owners, exactness of Gamma/F, SAP, NR2, EPPA
and joint lifting do not occur in this proof.

## N03: Actual imaginary parameters and the induced union language

B is a finite set of actual E-classes. Each is named INDIVIDUALLY. The
ambient named stabilizer H=Aut(M/A,B) fixes every such class as an imaginary
parameter. A setwise stabilizer is a different group. Choosing real class
representatives as named parameters would also be a different group.

The full union N_B is pi_E^-1(B), with literal old fine colours and a
predicate for each owner. Any thin functions used below are only definitional
expansions of their existing unique-neighbour old colour graphs. Arbitrary
new predicates are excluded: they could destroy the restriction action
and alter algebraicity. The full group K=Aut(N_B/A) refers to precisely
this owner-named induced structure. Naming owners shrinks the ambient
stabilizer, so F[A] retains finite orbit under H and lies in ambient real
acl over A together with B. The reverse inclusion is N04.

## N04: Local forward harmless-owner proof without countability

This proof is the unique-direction specialization of B022 C28-C30, whose
broader packaged type retains countability. We give every step rather than
assuming a new countability-free compiled provider.

Fix x outside F[A]. For each named E-class C and each old atomic colour p
call p bad if E intersect(p;p) is contained in F. If b,bprime are both
p-neighbours of x inside C, then bEbprime and b(p;p)bprime by symmetry.
They are F-related. Consequently the entire set of such neighbours in C
lies in a SINGLE finite F-class. There are only finitely many old colours,
so the union of their bad-neighbour sets inside C is finite.

Each named C is itself an INFINITE E-class. Choose b_C outside that finite
union AND outside {x}. This last exclusion is necessary when x belongs
to C. Then p_C=col(x,b_C) is genuine diversity and is not bad. The invariant
EQUIVALENCE E intersect Gamma(p_C) contains E intersect(p_C;p_C). The latter
is not contained in F, so the equivalence cannot be finite-class, because
every finite-class invariant equivalence is below F. Minimality of infinite
E forces E intersect Gamma(p_C)=E. Thus E<=Gamma(p_C).

By N02 the same E also lies in every original real spoke equivalence.
Hence E[x] is contained in the canonical hull for the finite real set
A union {b_C:C in B}. All spokes are diversity: x is neither an original
A point nor any chosen b_C. The hull is infinite. The canonical-hull
contrapositive shows x is not algebraic over this REAL parameter set.
If that set is empty, use the infinite transitive empty-base argument.

Each actual imaginary C is definable from b_C. Thus the full real stabilizer
of A and all b_C is a subgroup of H=Aut(M/A,B). Its x-orbit is infinite by
the preceding paragraph, so the larger H-orbit is infinite as well. In
equivalent definability language, algebraicity over A and B would imply
algebraicity over A and the chosen representatives, a contradiction.
Representatives are only proof choices, never the actual named parameter
contract. Together with N03 this proves

`acl_M^eq(A union B) intersect M = F[A] = acl_M(A)`.

The proof handles A empty, B empty, repeated actual owner values merged
as a set, and a named class containing x. It uses no owner exactness,
normalization, thin group, countability, homogeneity of N_B or joint lift.
The reverse harmless-owner necessity theorem is not needed or re-exported.

## N05: Normalization, induced owner action and total definable functions

Only now assume there is no nonidentity finite-class full exact kernel.
If any F atom were nonthin, the explicit finite-regularization provider
C22 would construct a NONIDENTITY finite-class full exact kernel, contrary
to normalization. This LOCAL contraposition makes every F atom thin.
We do not import the broader countability-bundled normalization chain.
Its
unique-neighbour maps, including equality as identity, form the finite
elementary abelian group G of literal translations. The group acts freely
and transitively within every actual real F-packet. Its maps are 0-definable
by old colour names and are original-global automorphisms; no packet origins
or charts have been chosen.

Since E is invariant under original automorphisms, each t_g induces a
well-defined action on actual M/E. That owner action need not be faithful
or free: elements may fix all owners while moving real points. If B is
invariant under this action, t_g maps its entire preimage N_B to itself.
Consequently every F-packet meeting N_B is contained in N_B. Conversely,
if every such full packet is contained, choose any real a above b in B.
The owner of t_g(a) is g b and remains in B, proving G invariance. Empty
B gives the empty union and satisfies the same equivalence directly.

Thus all t_g restrict to TOTAL functions on N_B. The graph of each remains
its original named thin colour, with a unique output, so each value t_g(a)
is individually definable from a IN N_B. For finite A subset N_B,

`F[A] = {t_g(a):g in G,a in A} subset dcl_N_B(A)`.

This is stronger than merely saying the finite SET F[A] is definable;
the latter alone would imply only algebraicity of its elements. Finiteness
and preservation of the old functional graphs give the stated lower acl
inclusion. A t_g can permute the distinct named owner predicates, and is
therefore NOT assumed to be in Aut(N_B) with all owner names fixed.

If G invariance is dropped, take b in B and g b outside B and choose a
over b. Then t_g(a) belongs to F[a] but lies outside N_B. Literal equality
of acl_N_B(A) with the WHOLE ambient F[A] is then impossible. Merely
intersecting an ambient packet is not the conclusion being prepared.
Unique minimal E is still needed from N02/N04; full normalization alone
does not imply unary real closure in a multidirection source.

## N06: Restriction IMAGE and full induced-structure algebraicity

Every h in H=Aut(M/A,B) preserves each named class, hence the whole union,
every literal original relation and every definable thin graph. Restrict h
to N_B. This defines a homomorphism H->K=FULL Aut(N_B/A). Its IMAGE is a
subgroup of K. Restriction need not be injective: ambient automorphisms can
act outside the union. It need not be onto K: not every automorphism of
the induced union has been lifted ambiently.

For x in N_B the image-subgroup orbit equals its ambient H-orbit as an
actual set of points, and is contained in the K-orbit. If x is outside
F[A], N04 makes the H-orbit infinite; it lies wholly in N_B. Therefore
the full K-orbit is infinite, excluding x from acl_N_B(A). Combined with
N05's finite definability this proves

`acl_N_B(A) = F[A] = acl_M^eq(A union B) intersect N_B`.

No homogeneity of N_B or joint lifting is used. For A empty the right hand
side is empty; N04/N06 establish the same for the induced union, even
though that structure need not be transitive across its named owners.
For B empty there are no real points and A must be empty, so the set
equalities are direct. Keep this case outside any API insisting source
carriers be nonempty. Finally any finite full-F union C in N_B satisfies
F[C]=C and is absolutely closed there by this formula.

Finite permutation diagnostics can check the orbit-containment direction,
group-image distinction, functional totality and packet saturation. In a
FINITE actual structure every point is algebraic even over empty input;
these finite controls do not prove the infinite-source closure equalities.
